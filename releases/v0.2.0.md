# Pricing Plugin v0.2.0 — industrial pricing skills

Seven independently installable skills for B2B industrial products and spare parts cover company context, margin analysis, opportunity assessment, recommendations, pricing strategy, rollout planning, and request triage. Each skill bundles its supporting references and MIT license.

## Install from GitHub

Paste this into Codex:

```text
$skill-installer Install these skills from https://github.com/Schadenfreunde/Pricing-plugin:
- skills/pricing-intake
- skills/pricing-analyze
- skills/pricing-scan
- skills/pricing-recommend
- skills/pricing-design
- skills/pricing-execute
- skills/pricing-triage
```

Keep only the paths you want to install. If the skills do not appear, restart Codex. See the [official skill installation guidance](https://learn.chatgpt.com/docs/build-skills#install-curated-skills-for-local-use).

Keep validated company facts in `.pricing/context.md` in your working project. The intake skill proposes context and saves only facts you validate.

## Downloadable package

`pricing-plugin-v0.2.0.zip` contains one `pricing-plugin/` folder with 83 runtime files: the manifest, README, root MIT license, and seven complete skill folders. Pricing references are bundled inside the six skills that use them; report guidance is bundled inside the five skills that use it. The intake skill includes its context outline.

The ZIP excludes evaluation fixtures, independent answer keys, authoring sources, and repository artwork. `SHA256SUMS` records the archive's SHA-256 digest. After downloading both files, verify integrity with:

```sh
shasum -a 256 -c SHA256SUMS
```

A checksum checks byte integrity; it is not a signed provenance attestation.
