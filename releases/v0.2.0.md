# Pricing Plugin v0.2.0 — industrial pricing skills (pilot)

This pilot expands Pricing Plugin from intake and margin analysis to seven skills for industrial products and spare parts. It adds pricing opportunity assessment, recommendations, strategy design, rollout planning, and request triage. Installation acceptance is pending; this release remains a draft until that check is complete.

## Changes

- Added `pricing-scan`, `pricing-recommend`, `pricing-design`, `pricing-execute`, and `pricing-triage` alongside `pricing-intake` and `pricing-analyze`.
- Added six curated methods: value estimation, segmentation, peer comparisons, price realization, discount governance, and price-change economics.
- Documented prior-period fixed-basket price scenarios, evidence confidence, and the distinction between calculated effects and unproven commercial causes.
- Improved the README, capability FAQs, synthetic margin example, and package metadata.
- Added the MIT license and its notice to the runtime package.

## Downloads

Use **`pricing-plugin-v0.2.0.zip`** to install the plugin. It contains one `pricing-plugin/` folder with exactly 22 runtime files: the manifest, README, MIT license, seven skills, their two supporting references, and nine pricing knowledge references.

Use **`SHA256SUMS`** to check the ZIP's SHA-256 digest. Save both files in the same directory, then run one of:

```sh
# macOS
shasum -a 256 -c SHA256SUMS

# Linux
sha256sum -c SHA256SUMS
```

The checksum checks byte integrity; it is not a signed provenance attestation. GitHub's automatically generated source archives contain the full repository, including evaluation material. Use the runtime ZIP for the pilot, so independent evaluation answer keys are not installed with the plugin.

## Local installation

1. Verify the ZIP checksum and extract the ZIP.
2. Place its `pricing-plugin/` folder under `plugins/` in your working repository.
3. Add or merge this entry into that repository's `.agents/plugins/marketplace.json`. The source path is relative to the repository root.

```json
{
  "name": "pricing-local",
  "plugins": [
    {
      "name": "pricing-plugin",
      "source": { "source": "local", "path": "./plugins/pricing-plugin" },
      "policy": { "installation": "AVAILABLE", "authentication": "ON_INSTALL" },
      "category": "Productivity"
    }
  ]
}
```

4. Restart the ChatGPT desktop app, select `pricing-local` in the Plugins Directory, and install `pricing-plugin` in a supported local Codex session.
5. Verify all seven skills are discovered and their relative references load in a fresh session. This acceptance check has not yet been completed for this package.

Company context belongs in `.pricing/context.md` in the working project, outside the plugin. The intake skill saves only facts you validate. Follow the [official OpenAI packaging guide](https://developers.openai.com/plugins/build/plugins) for local marketplace setup.

## Validation and known limitations

Local package checks verify metadata, the MIT declaration, all 22 runtime files, and runtime reference closure. They do not establish installed-host behavior or business accuracy.

- Fresh installed-host discovery and reference-loading acceptance remain pending at the user's request.
- Compatibility with other hosts and public plugin-directory availability are not established.
- Synthetic examples are illustrations, not customer results or performance benchmarks.
- Fixed-volume price scenarios are conditional calculations, not demand forecasts or guaranteed benefits.
- The plugin has no bundled calculation engine, MCP server, or ERP integration. It uses available host tools.
- Detailed account/product execution targets and negotiation support remain outside the current scope.
- Sample PDF export and page-by-page PDF inspection are unverified.
