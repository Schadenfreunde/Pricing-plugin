# Pricing knowledge index

Open only the reference relevant to the question. These notes support judgment; they do not prescribe a fixed analysis sequence or substitute for a company's validated definitions and policies.

| Question | Reference |
| --- | --- |
| Is a reported margin movement comparable and correctly calculated? | [Metric verification](metric-verification.md) |
| Which observed price, cost, and mix changes account for a margin movement? | [Margin drivers](margin-drivers.md) |
| Which defined price step or adjustment changed, and was it permitted? | [Price waterfall](price-waterfall.md) |

Use the evidence available for the task. If only aggregate totals exist, verify the movement and state the limit on driver attribution. Investigate peer prices only when comparable peers and a relevant price question justify it; no peer-price method is required for the initial margin case.
