# PDF export

Export a static landscape PDF with readable slide-like pages unless the user requests otherwise. Choose page breaks for the material; split dense content rather than shrink or clip it.

Preserve scope, figures, labels, caveats and methods. Show essential content without hover/controls and keep controls from covering content.

Inspect every page of the actual export before providing it. CSS alone cannot confirm an actual export. If export or inspection is unavailable, report that limit and provide only the verified artifact.
