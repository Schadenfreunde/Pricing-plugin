# HTML reporting

For useful artifacts, default to a neutral professional scrolling page with slide-like sections; respect requested format/depth. Lead with conclusions and material qualifications, including unvalidated dependencies beside affected findings; follow with a brief method note.

Generate self-contained HTML with available host tools. Use already computed figures in charts/tables; JavaScript handles presentation only. Add controls when they clarify the view, with explicit labels/filter scope. Embed only needed data; essential information must remain available without hover or controls.

Inspect the actual screen view before sharing. For substantial circulation reports, default to landscape PDF unless another format is requested; for any PDF deliverable, load [PDF export](pdf-export.md).
