# Pricing knowledge index

Open only the references needed for the question. These notes support judgment; they do not prescribe a fixed analysis sequence or substitute for a company's validated definitions and policies.

| Question | Reference |
| --- | --- |
| Is a reported margin movement comparable and correctly calculated? | [Metric verification](metric-verification.md) |
| Which observed price, cost, and mix changes account for a margin movement? | [Margin drivers](margin-drivers.md) |
| Which defined price step or adjustment changed, and was it permitted? | [Price waterfall](price-waterfall.md) |
| How much did comparable realized prices change, holding the prior basket fixed? | [Price realization](methods/price-realization.md) |
| What are a price change's conditional revenue/contribution effects and response limits? | [Price-change economics](methods/price-change-economics.md) |
| Are price differences meaningful among comparable customers/products, and what needs validation? | [Peer comparisons](methods/peer-comparisons.md) |
| Which pricing guidance or scoped exception applies, and how should deviations be assessed? | [Discount governance](methods/discount-governance.md) |
| What differentiated value does an offer create relative to the buyer's alternative? | [Value estimation](methods/value-estimation.md) |
| Which customer/product/term differences justify a workable pricing structure? | [Segmentation](methods/segmentation.md) |

Use the evidence available for the task. If only aggregate totals exist, verify the movement and state the limit on driver attribution. Use peer comparisons when the price question warrants them; if comparability is weak, state that limit. No peer-price method is required for the initial margin case.
